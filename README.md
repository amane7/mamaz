# 🌸 Manary+ — 助産師さんとママの応援団

> [**Manary**](https://manary.care/) の世界観・作風を完全踏襲し、ブラッシュアップした次世代型 SaaS プロトタイプです。

産後ケア・助産院の現場で日々生まれる「紙のカルテ」「LINEで届く写真」「電話での予約」を、やさしくひとつにまとめた **B2B SaaS（助産師向け）+ B2C2B（ママ向けコンパニオン）** の体験を実装しています。

ブランドカラーは Manary の **桜ピンク × ココアブラウン × クリーム** を踏襲し、丸ゴシック (Zen Maru Gothic) と熊のマスコット「**まなくん**」で、医療系プロダクトの硬さを徹底的にやわらかく置き換えました。

---

## 🧭 3つのモード

ランディングページから役割を選ぶと、それぞれ最適化された画面に遷移します。

### 1. 🏥 助産師アプリ (`MidwifeApp`)

紙のカルテ・予約ノート・LINE 相談を 1 画面に統合した、助産院オーナー向けのダッシュボードです。

| タブ | 役割 |
| --- | --- |
| 🏠 **ダッシュボード** | 今日のKPI／本日の予約／AIインサイト／緊急チャット |
| 📅 **カレンダー** | 週ビュー（8-17時 × 7日）、予約タイプ別カラー |
| 👥 **利用者** | ママ一覧、リスクフラグ（乳房/メンタル/体重/睡眠） |
| ✍️ **カルテ** | SOAP 形式 + AI 下書きボタン、写真タイムライン、体重グラフ |
| 📊 **分析** | 来院数・サービス別・リピート率 |
| 💬 **受信箱** | ママからの相談、AI トリアージ（緊急度自動判定） |

### 2. 👶 ママアプリ (`MamaApp`)

退院後のママが、スマホ片手で安心して助産師さんとつながれるコンパニオンアプリです。

| タブ | 役割 |
| --- | --- |
| 🏠 **ホーム** | 次の予約／助産師からの返信／クイックアクション |
| 📝 **きょうの記録** | 9問の優しい問診（睡眠/気分/痛み/出血/乳房/体重 ほか） |
| 📸 **写真** | カテゴリ別（乳房/便/発疹/体重計）でセキュアに共有 |
| 💬 **相談** | 助産師さんと直接チャット、🆘 緊急ボタン |
| 🗓️ **来訪** | 次回・過去の予約一覧 |

### 3. 🌐 ランディングページ (`Landing`)

Manary 公式サイトの構成（ヒーロー／特徴／改善ポイント／料金／お客様の声／FAQ／CTA）を踏襲しつつ、**ダークモード対応・AI予測カード・モックダッシュボード**などのモダンな要素を追加しています。

## 🤖 AI レイヤー (`src/ai.ts`)

すべてルールベースで実装 → 将来 LLM に差し替え可能な設計です。

- **`analyzeIntake()`** — ママの問診からインサイトを自動生成
  - メンタル（気分≤4 or 睡眠≤4h → EPDS推奨）
  - 乳房ケア（しこり・発赤 → 乳腺炎の疑い）
  - 体重（成長曲線から逸脱）
  - 授乳頻度・出血量・ポジティブ状態
- **`suggestSOAP()`** — 問診から SOAP カルテのドラフトを自動作成
- **`triageMessage()`** — チャット内の「出血」「発熱」「自傷」等を検知し緊急フラグ

## 🎨 デザインシステム

Manary を踏襲した、医療プロダクトらしくない「あったかさ」を最優先。

- **カラー**: `sakura` `peach` `cocoa` `cream` `night` (Tailwind カスタムパレット)
- **フォント**: Zen Maru Gothic / Quicksand / Nunito
- **マスコット**: まなくん (`<Manakun mood="smile" />` 5表情切替)
- **コンポーネント**: `.card` `.chip` `.btn-primary` `.bubble` `.hand-underline`
- **ダークモード**: Tailwind `darkMode: 'class'` で切替
