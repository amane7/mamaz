# 🌸 mamaz — 産後のあなたに寄り添うAIケアパートナー

> 「産後ケアアプリの構成案と未来志向のアイデア」を実装した、Web版プロトタイプです。

産後のママ・パパに向けて、**記録・癒し・つながり・予測ケア**を一つにまとめた次世代の産後ケアアプリ。
AIアシスタント **mami** が育児・心身ケアを伴走し、未来志向の機能で家族をやさしく支えます。

---

## 🧭 アプリ構成

### コア体験（6つのタブ）

| タブ | 役割 | 主な機能 |
| --- | --- | --- |
| 🏠 **ホーム** | 今日のダッシュボード | AI提案カード／ウェルネススコア／24h授乳・睡眠・おむつサマリ／次の授乳予測／月齢別ヒント |
| 📝 **記録** | 育児ログ | 授乳・睡眠・おむつ・気分・メモのワンタップ記録／7日トレンドのチャート |
| 💬 **mami** | AIケアパートナー | ルールベースAI mami との対話／緊急時のホットライン案内／クイック質問 |
| 🌸 **ママ** | セルフケア | コンディションのレーダーチャート／EPDS産後うつスクリーニング／専門連絡先 |
| ✨ **未来ケア** | Future Lab | 泣き声AI解析／予測ケア／音声ログ／パートナー連携／AR遊び／家族の絆ガーデン |
| 👥 **みんな** | コミュニティ | 月齢別タイムライン／タグ／専門家オンライン相談 |

### 🚀 未来志向のアイデア（実装済みプロトタイプ）

1. **泣き声AI解析** — 5パターン (空腹／眠い／おむつ／不快／甘え) を推定。オンデバイス推論を想定。
2. **予測ケア (24h)** — 過去ログから次の授乳タイミングを予測。信頼度つきで時系列表示。
3. **ボイスログ** — Web Speech API でハンズフリー記録。構造化AIで自動ログ化。
4. **パートナーシンク** — 共有コードでパートナー端末と連動。ママの疲労サインをパートナーに通知。
5. **AR視覚刺激プレイ** — 月齢に合わせた高コントラスト映像で視覚発達を支援。
6. **家族の絆ガーデン** — 記録量に応じて庭に花が咲く、ジャーニーの可視化。
7. **EPDS スクリーニング** — エジンバラ産後うつ自己評価票（10問）で早期発見をサポート。
8. **AIモデレーション** — コミュニティ投稿は AI が見守り、安全な発言環境を担保。

## 🛠 技術スタック

- **Frontend**: React 18 + TypeScript + Vite 5
- **Style**: TailwindCSS 3 (mama/moon/cream のカラーパレット)
- **Chart**: Recharts (Bar / Line / Radar)
- **State**: 自作軽量ストア (`useAppState`) + localStorage 永続化
- **AI ロジック**: ルールベースの `mami` モジュール (LLM API へ差し替え可能な構造)

## 🌈 デザイン哲学

- **やさしさファースト**: 産後の睡眠不足でも目に痛くない、ピンク×ラベンダー×クリームのトーン
- **片手操作**: 抱っこ中でも使えるよう、主要アクションは下部ナビと大きめタップターゲット
- **共感する言葉**: AI mami の応答はジャッジせず、まず寄り添うトーン
- **緊急時は迷わず**: 自傷ワード検知でホットラインへ即誘導
